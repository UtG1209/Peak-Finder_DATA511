3D dashboard options

Stills of three candidates. The live, rotatable versions with real data are in docs/design/hike-page/3d-options.html (three.js 0.170, drag to orbit, nothing auto-rotates). Each has a 2D fallback and a text table.

A. Recommended

Terrain ribbon

Answers: what does the climb feel like, where is the steep part, where am I at 09:10. Linked to the 2D profile scrubber (same state). Gentle teal, steep terracotta.

B. Optional

Match landscape

Answers: how wide is my window if I move my limit? Height = fit. Best for the "When" question but harder to read than the 2D chart; ship only with the table and the 2D month chart beside it.

C. Optional

Hike galaxy

Answers: which hikes are like this one, in length, gain and climate together. Replaces the 2D scatter only on desktop; 2D scatter stays for phone and for keyboard use.
